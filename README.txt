1) أنشئ مستودعاً جديداً على github.com (Repository) وارفع كل محتويات هذا المجلد إليه (بما فيها المجلد المخفي .github).
2) افتح تبويب Actions ثم Build APK ثم Run workflow (أو سيعمل تلقائياً عند الرفع).
3) بعد دقائق، افتح عملية البناء ونزّل الملف app-debug-apk من قسم Artifacts، ثم فك الضغط لتجد app-debug.apk.
4) انقل الملف إلى الهاتف وثبّته (فعّل "التثبيت من مصادر غير معروفة").
